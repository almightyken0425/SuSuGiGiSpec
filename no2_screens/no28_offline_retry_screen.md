# 離線重試: OfflineRetryScreen

## 畫面目標

- App 無帳號 UI 下唯一的攔路畫面
- 首開離線或資料清除收尾未決時顯示，連網重試後續走匿名 bootstrap
- 觸發條件與重試行為由 AnonymousBootstrapLogic 與 DeleteUserAccountLogic 承載

---

## 佈局

### 內容區

- 品牌標誌置中
- 說明文案
  - **IF** 卡點為首開離線:
    - 說明首次啟動需要網路連線完成初始化，之後即可離線使用
  - **IF** 卡點為資料清除收尾未決:
    - 說明資料清除需要網路連線完成收尾
- 重試 按鈕
- 版權行
- 視覺定案由對側 Design git 承載

---

## 互動

- **點按重試:**
  - 呼叫 retryBootstrap，以當前身分狀態重驅一輪 bootstrap
  - 重試期間回到啟動載入狀態，本畫面卸載
  - **IF** 重試成功:
    - 進入主畫面路線
  - **IF** 重試失敗:
    - 回到本畫面，文案依卡點型態顯示
