# 刪除使用者帳號流程: DeleteUserAccountLogic

## 目的

- 提供 app 內完成帳號永久刪除的編排，先刪雲端再清本機
- 與登出及換帳號清除刻意區隔：僅刪除被刪帳號的資料，裝置上其他帳號資料保留
- 與記帳帳戶刪除的 deleteAccount 為不同概念，本流程一律以 deleteUserAccount 識別

---

## deleteUserAccount 刪除使用者帳號

- 最終確認通過後呼叫，統籌刪除旗標、同步屏障、Apple 重新授權、伺服器刪除與本機收尾
- **性質:**
  - 非同步，需處理網路、Apple 授權與伺服器錯誤
  - 失敗會拋回呼叫端，由畫面依錯誤碼顯示對應提示
- **執行:**
  - **IF** 裝置離線:
    - 拋出網路錯誤並中止，不進入任何副作用
  - 設起記憶體刪除旗標
    - 記憶體旗標讓交易備份、授權補驗與購買監聽即時跳過，避免刪除中把資料寫回雲端
    - 流程結束不論成敗一律解除；不解除會把之後登入的其他帳號的備份與恢復購買一併停掉
    - 持久旗標另於委派伺服器前寫入，分已送出與已完成兩階段，供中斷復原判斷
  - 等待進行中的交易備份收斂後才往下
    - 說明段的訂閱管理跳轉返回時可能觸發前景備份，不等待會與伺服器刪除交錯
  - **IF** 登入門為 Apple:
    - 以刷新模式喚起 Sign in with Apple 原生授權，取得當次授權碼
    - **IF** 重新授權遭取消:
      - 清除刪除旗標並拋出取消，畫面靜默中止
    - **IF** 重新授權因其他原因失敗:
      - 降級為不附授權碼續行，撤銷交由手動引導補救
      - 取不到授權碼不得把帳號刪除鎖死
  - 以已送出階段寫入持久旗標，隨即委派至伺服器端 AccountDeletionLogic 的 deleteUserAccount，Apple 門附上當次授權碼
    - 持久旗標於委派前一刻才寫：更早寫的話，授權面板階段被終止會留下帳號其實沒動的誤導旗標
  - **IF** 委派結果不明，如途中斷網或逾時:
    - 持久旗標維持已送出階段並拋出錯誤；伺服器可能已刪完，交由刪除中斷復原以憑證判定
  - **IF** 伺服器明確回報失敗:
    - 清除持久旗標並拋出錯誤，本機資料維持原狀、可整段重試
  - **ELSE:**
    - 持久旗標升為已完成階段，帳號自此確定已刪
    - 委派至 destroyUserData 硬刪本機該帳號資料
    - **IF** 本機硬刪成功:
      - 清除換帳號偵測的最後登入帳號紀錄
      - 清除刪除旗標
    - **ELSE:**
      - 保留最後登入帳號紀錄與持久旗標
      - 殘留列於使用者在換帳號詢問選擇清除、或下次啟動的旗標復原時回收；選擇保留則殘留續存
    - 清除該帳號的本地授權快取
    - 觸發 Firebase Auth 登出，清除本地登入憑證並回到登入牆
- **回傳:**
  - 刪除成功與否，以及 Apple 授權撤銷是否完成
- **理由:**
  - 授權碼僅數分鐘且單次有效，故於刪除當下重新授權取得，不沿用登入時的碼
  - 同步屏障排在喚起授權面板前，慢速上傳才不會把授權碼耗到過期
  - 先伺服器後本機：伺服器刪除失敗時本機資料未動，可原地重試
  - 撤銷未完成不擋刪除，由畫面引導於系統設定手動撤銷

## destroyUserData 硬刪本機帳號資料

- 伺服器刪除成功後呼叫，硬刪本機屬於該帳號的所有紀錄
- **性質:**
  - 非同步，單一批次寫入，重跑刪除零列、天然冪等
- **執行:**
  - 依資料庫綱要推導帶帳號欄位的資料表清單，逐表以帳號過濾取列
  - 使用者資料表無帳號欄位，以帳號識別碼取那一列併入
  - 全部命中列以硬刪方式收進單一批次寫入
  - 不逐筆標記刪除、不傳播雲端刪除標記，雲端已由伺服器刪畢
  - 裝置上其他帳號的資料列保留
- **理由:**
  - 與換帳號清除的整庫硬重置刻意不同：刪帳號只允許動被刪帳號的列
  - 表清單由綱要推導，新增資料表自動涵蓋、不靠人工維護

## 刪除中斷復原

- 登入狀態監聽於每次觸發時檢查持久旗標，補救收尾被中斷的刪除
- **性質:**
  - 伺服器刪除成功後、本機收尾完成前 app 被終止，重啟必須不重建雲端資料
- **執行:**
  - **IF** 持久旗標存在且與當前登入帳號相符:
    - 以強制刷新登入憑證判定帳號是否已刪
    - **IF** 憑證刷新回報帳號不存在:
      - 補跑本機收尾並登出，跳過登入後初始化
      - 登入後初始化會重建剛刪除的雲端文件並回傳本機殘留，絕不可執行
    - **IF** 憑證刷新成功:
      - 刪除未越過伺服器執行點，清除旗標走正常流程，可重新發起刪除
    - **IF** 刷新以其他原因失敗:
      - 判定不明，保留旗標並跳過本輪，停在登入牆待下次觸發再判
      - 每次啟動至多提示一次需要網路完成刪除，不隨監聽重觸發轟炸
  - **IF** 已登出且持久旗標為已完成階段:
    - 帳號確定已刪，直接補跑本機收尾
  - **IF** 已登出且持久旗標為已送出階段:
    - 不動本機資料，待重新登入時以憑證判定
- **理由:**
  - 已簽發的登入憑證於帳號刪除後仍短暫有效，單看登入狀態不足以判定
  - 誤把存活帳號的本機資料清除等同資料遺失，判定不明時寧可保留
  - 只認帳號不存在一種證據：憑證過期、憑證失效、帳號停權皆可由改密碼、其他裝置撤銷連線階段等原因造成，當成已刪會硬刪仍存在帳號的資料
  - 登出態沒有任何憑證可判定，故只補跑已完成階段；已送出階段的伺服器結果不明，此時硬刪等同砍掉可能仍存在帳號的全部本機資料
