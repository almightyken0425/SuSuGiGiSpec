# 資料管理: DataManagementScreen

## 畫面目標

- 提供資料匯入、匯出與清除的集中管理介面

---

## 佈局

### 導覽列

- Header 模式: A
- 返回按鈕
- 資料管理 標題

### 設定列表

- List 模式: A
- 各分組以空白間距區隔
- 不顯示分組標題文字
- 第一組
  - 匯入收入支出 入口
  - 匯入轉帳 入口
- 第二組
  - 匯出收入支出 入口
  - 匯出轉帳 入口
- 第三組
  - 清除所有資料 入口
    - 清除所有資料為破壞性操作
    - 清除進行中入口停用並顯示進度指示
    - 視覺定案由對側 Design git 承載

---

## 互動

- **點按返回按鈕:**
  - 返回上一頁

- **點按匯入收入支出:**
  - 導航至 ImportWizardScreen，帶入交易模式

- **點按匯入轉帳:**
  - 導航至 ImportWizardScreen，帶入轉帳模式

- **點按匯出收入支出:**
  - 呼叫 exportToCsv，匯出類型 交易
  - **IF** 操作中:
    - 阻擋重複觸發直到完成
  - **IF** 無資料可匯出:
    - 顯示無資料對話框
  - **IF** 操作失敗:
    - 顯示匯出失敗對話框

- **點按匯出轉帳:**
  - 呼叫 exportToCsv，匯出類型 轉帳
  - **IF** 操作中:
    - 阻擋重複觸發直到完成
  - **IF** 無資料可匯出:
    - 顯示無資料對話框
  - **IF** 操作失敗:
    - 顯示匯出失敗對話框

- **點按清除所有資料:**
  - 顯示清除說明對話框
    - 對話框須預告：App 內與雲端備份的全部資料將永久清除、App 身分將重設且不可復原
    - **IF** 目前訂閱等級為付費:
      - 對話框須註明：訂閱不受影響，訂閱跟隨 Apple ID 繼續有效；停止扣款須至 App Store 訂閱管理取消
      - 提供前往訂閱管理的選項，點按後以外部瀏覽開啟 App Store 訂閱管理頁
  - **IF** 確認繼續:
    - 顯示最終確認對話框，確認選項為破壞性樣式
    - **IF** 確認清除:
      - 呼叫 deleteUserAccount
      - **IF** 操作成功:
        - 清除完成後自動重生新匿名身分，畫面回到主畫面路線
        - **IF** 回報 legacy Apple 授權撤銷未完成:
          - 顯示手動撤銷引導，指引至系統設定的 Apple 帳號登入與安全性頁面
        - **ELSE:**
          - 顯示清除完成訊息
      - **IF** 操作失敗:
        - 顯示錯誤提示，提示不承諾資料維持原狀、引導重試完成清除
