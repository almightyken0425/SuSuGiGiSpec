# 匯率編輯器: CurrencyRateEditorScreen

## 畫面目標

- 提供更新幣別對匯率的介面

---

## 線框圖

```text
+--------------------------------+
| [X]        Set Rate       [✓]  |
+--------------------------------+
|                                |
| [ From Cur ]      [ To Cur ]   |
|                                |
| [ Amount A ]  =  [ Amount B ]  |
|                                |
+--------------------------------+
```

---

## 佈局

### 導覽列

- Header 模式: C
- 關閉按鈕
- 設定匯率 標題
- 完成按鈕
  - **IF** 輸入欄位未填妥:
    - 不可點按

### 幣別對顯示區

- 來源幣別代碼
- 目標幣別代碼
- 來源幣別鎖定為主要貨幣，不可修改
- 目標幣別由匯率列表點選的幣別對帶入，不可修改

### 匯率輸入區

- 來源金額輸入框
  - 預設值 1
  - 依輸入欄位共用政策
  - 即時只接受數字字元與單一小數點，其餘輸入不更新
  - 達字元上限即時阻擋，輸入不再更新
- 等號標籤
- 目標金額輸入框
  - 預填 1 單位主要貨幣對應的外幣數量
  - 依輸入欄位共用政策
  - 即時只接受數字字元與單一小數點，其餘輸入不更新
  - 達字元上限即時阻擋，輸入不再更新

---

## 互動

- **點按關閉按鈕:**
  - 返回上一頁

- **點按完成按鈕:**
  - 呼叫 createCurrencyRate
  - **IF** 操作成功:
    - 返回上一頁
  - **IF** 操作失敗:
    - 顯示錯誤提示
