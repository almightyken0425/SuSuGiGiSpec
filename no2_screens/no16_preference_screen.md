# 偏好設定: PreferenceScreen

## 畫面目標

- 提供設定 App 核心行為的介面

---

## 線框圖

```text
+--------------------------------+
| <           Preferences        |
+--------------------------------+
|  Launch Mode: Default >        |
+--------------------------------+
|  Base Currency: TWD >          |
|  Currency Format Settings >    |
|  Exchange Rates >              |
+--------------------------------+
|  Language: 繁體中文 >          |
|  Time Zone: Asia/Taipei >      |
|  Week Start: 跟隨語系 >        |
+--------------------------------+
|  Allow Data Analytics    [ON]  |
+--------------------------------+
|  Logout                        |
|  Delete Account                |
+--------------------------------+
```

---

## 佈局

### 導覽列

- Header 模式: A
- 返回按鈕
- 偏好設定 標題

### 設定列表

- List 模式: A
- 各分組以空白間距區隔
- 不顯示分組標題文字
- 第一組
  - 啟動模式 入口
    - 顯示當前啟動模式
- 第二組
  - 主要貨幣 入口
    - 顯示當前設定的主要貨幣代碼
  - 貨幣格式設定 入口
  - 匯率管理 入口
- 第三組
  - 語系 入口
    - 顯示當前 App 語言
  - 時區 入口
    - 顯示當前設定的時區
  - 週起始日 入口
    - 顯示當前週起始日選項
- 第四組
  - 分析同意 開關
    - 顯示 analyticsConsent 目前狀態
- 第五組
  - 登出 按鈕
  - 刪除帳號 按鈕
    - 破壞性樣式紅字
  - 刪除進行中本組按鈕全部停用，刪除帳號另顯示進度指示

---

## 互動

- **點按返回按鈕:**
  - 返回上一頁

- **點按啟動模式:**
  - 導航至 LaunchModeSettingScreen

- **點按主要貨幣:**
  - 導航至 BaseCurrencySettingScreen

- **點按貨幣格式設定:**
  - 導航至 CurrencyListScreen

- **點按匯率管理:**
  - 導航至 CurrencyRateListScreen

- **點按語系:**
  - 導航至 LanguageSettingScreen

- **點按時區:**
  - 導航至 TimeZoneSettingScreen

- **點按週起始日:**
  - 導航至 WeekStartSettingScreen

- **切換分析同意開關:**
  - 呼叫 setAnalyticsConsent
  - 即時生效

- **點按登出:**
  - 顯示登出確認對話框
    - 對話框須預告：登出後若以其他帳號登入此裝置，本機資料可被清除且不可復原
  - **IF** 確認登出:
    - 呼叫 logout
    - **IF** 操作成功:
      - 導航至 LoginScreen
    - **IF** 操作失敗:
      - 顯示錯誤提示

- **點按刪除帳號:**
  - 顯示刪除說明對話框
    - 對話框須預告：帳號、雲端備份與本機該帳號資料將永久刪除且不可復原
    - **IF** 目前訂閱等級為付費:
      - 對話框須提醒：刪除帳號不會取消 App Store 訂閱，Apple 將持續扣款，須先自行取消
      - 提供前往訂閱管理的選項，點按後以外部瀏覽開啟 App Store 訂閱管理頁
  - **IF** 確認繼續:
    - 顯示最終確認對話框，確認選項為破壞性樣式
    - **IF** 確認刪除:
      - 呼叫 deleteUserAccount
      - **IF** 操作成功:
        - 隨登入狀態清除自動回到 LoginScreen
        - **IF** 回報 Apple 授權撤銷未完成:
          - 顯示手動撤銷引導，指引至系統設定的 Apple 帳號登入與安全性頁面
        - **ELSE:**
          - 顯示刪除完成訊息
      - **IF** 操作失敗:
        - 顯示錯誤提示，提示不承諾資料維持原狀、引導重試完成刪除
      - **IF** Apple 重新授權遭取消:
        - 靜默返回本畫面、不顯示錯誤
